# Project Statement

## Project Title
DNA Sequence Analyzer

## Problem Statement
DNA sequences are made up of four main nucleotide bases: A, T, G and C. Looking at a DNA sequence manually can make simple calculations such as counting nucleotides or finding GC content repetitive.

The DNA Sequence Analyzer is a beginner-level Python application that accepts a DNA sequence from the user and performs basic analysis and sequence operations.

## Scope
The project focuses on basic DNA sequence processing using Python. It is intended as an educational project and does not provide medical or clinical conclusions.

The application can:
- Accept a DNA sequence from the user
- Validate the sequence
- Count A, T, G and C
- Calculate sequence length
- Calculate GC and AT content
- Find the complement
- Find the reverse
- Find the reverse complement

## Target Users
- First-year students learning Python
- Students interested in basic bioinformatics
- Beginners who want to understand how programming can be applied to biological sequences

## High-Level Features
1. Sequence input and validation
2. DNA sequence analysis
3. DNA sequence operations
4. Error handling for invalid input
5. Automated tests
